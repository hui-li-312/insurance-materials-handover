- 名录日期、来源采集时间、元数据审核时间与发布验收时间是不同事实，不互相改写。
- 名录中的公司与官网关联仅建立来源发布者身份，不核实实际合同承保人、当前经营许可或当前在售。

- 独立元数据审核完成不等于已发布；原始冻结中的待审核状态保留，后续审读作为另一个时间层。
- 父子关系仅表达来源目录结构，不自动传递材料、合同归属、适用性或正文审核。
- 重合只按明确的字段或材料身份记录；不做同名合并，不因未匹配而增加新产品信用。
- 保留引用只展示允许标签与 null，不能通过原链接、指纹、备用目标或来源页作下载回退。
- 本轮已按真实公开提交与实际部署身份对账；以后每次发布仍须单独核对，历史采集状态和全公司缺口不随发布成功而关闭。
