# 地区全覆盖采集：公司先行的验收计划

更新日期：2026-10-27。范围沿用现有 11 个地区：HK、SG、MY、TH、ID、PH、VN、BN、KH、LA、MM。

## 为什么调整

当前资料基线有 4,713 个原件记录，但原件数量不等于保险公司或产品覆盖率。Krungthai-AXA Life 的官网产品目录此前未被现有泰国索引覆盖，说明必须先检查公司分母，再扩大产品和材料数量。AXA 财险与 Krungthai-AXA 寿险须按不同法律实体分别建档。

## 采集顺序与验收门槛

1. **地区 → 公司底表**：以当地监管名录为首选，保留原始名录时点、许可证状态、类别与分页证据。协会会员表只能作为有明确范围的补充，不能替代监管全量名单。再保险、专属保险、劳合社、停业／存续服务主体等分别标注，不混成面向消费者销售的公司数。
2. **公司 → 官网和销售渠道**：逐个实体记录官网、公开产品目录、团险、附加险及公开银行渠道入口。名单中每一项必须有处理状态，不能因为已有该品牌文件就视为整个实体已遍历。
3. **目录 → 全部公开产品项**：遍历实际分页、分类、语言和合法可访问的渠道。记录官方名称、URL、产品／附加险／计划／组合角色及来源。相同名称不自动合并，不把不同语言页面直接计成不同产品；停售或陈旧站点地图链接单列。
4. **产品 → 材料矩阵**：分别检查宣传册、主条款、附约、产品信息说明、利益表、申请书等。下载成功需核对格式、原字节 SHA-256 和实际内容类型；按钮文字或文件名不是合同身份的充分证据。
5. **证据与发布**：新增产品目录、实际原件取得、全文阅读、身份对应、严格核验是不同指标。未读完不标全文；宣传册不标主条款。公开输出仅使用经检查的必要元数据与允许传播的材料，内部标记、客户资料和待核隐私内容另行保留。

## 每个公司必须保留的状态

- 名录是否实际枚举，来源及其时点是否明确。
- 官网是否确认；产品目录未检查、部分检查、已遍历当前公开目录或访问阻塞。
- 已访问目录页和产品页数量、实际观察到的产品项、重复／历史候选项。
- 每种材料取得或缺失的状态；访问失败不是“该产品不存在”。
- 尚未覆盖的分支、语言、渠道及下一条可执行检查。

## “完整”的边界

只有一个明确名录范围的每家公司、相应公开目录及全部已发现分页均处理完，才可标记该范围的目录遍历完成。名录年份过旧、当前监管名单取不到、公司入口受限或渠道范围未知时，市场级覆盖仍为开放状态。

`当前公开目录已遍历` 不等于全部历史产品、所有个性化签发合同、全部代理专属产品或所有主条款已经取得。不能把覆盖率的未知分母写成 100%，也不能将文件审读数作为产品覆盖率。

## 失败处理和保留

记录真实 HTTP 状态及软拒绝页面。遇到同一来源的访问拒绝、登录墙、验证码或明确反自动化阻塞时停止依赖该入口的操作，不使用代理、登录绕过或隐藏接口规避。可继续处理不依赖该来源的其他公司。未知日期保留 null，不根据 URL 或下载时间推断发布日期。

所有已有原件、核验结论和历史版本保持可追溯。新的覆盖研究单独成批，未验收前不增加原资料库的正式原件、严格主文或产品补齐数字。
