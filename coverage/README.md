本批仅发布检查过的必要元数据。原始监管表、网页快照、联系人、内部执行日志、待核原件及受限文件不在此目录中。对拒绝访问、旧年份来源、无效链接和语言限制保留实际状态，不绕过限制，也不把读取失败写成没有产品。
